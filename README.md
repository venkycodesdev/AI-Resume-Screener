# 🤖 AI Resume Screener

An AI-powered Resume Screener built using **Python**, **Flask**, **HTML**, **CSS**, and **JavaScript**.

The application analyzes a resume against a job description, detects technical skills, calculates a matching score, identifies missing skills, and provides personalized recommendations to improve the resume.

---

# 🚀 Features

- 📄 Upload PDF and DOCX resumes
- 📝 Automatic resume text extraction
- 🎯 Job description matching
- 💡 Skill detection
- ✅ Matching skills analysis
- ❌ Missing skills analysis
- 📊 Resume score calculation
- ⭐ ATS Rating
- 💪 Resume strength analysis
- 📈 Category-wise skill gap analysis
- 🤖 AI-based improvement suggestions
- 🎯 Final recommendation dashboard
- 📱 Responsive user interface

# ⚙️ Installation

Clone the repository

```bash
git clone <repository-link>
```

Move into the project folder

```bash
cd AI-RESUME-SCREENER
```

Create a virtual environment

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
